# 新增排期与任务池双向切换

- Status: awaiting_user_acceptance
- Revision: r1
- Confirmed date: 2026-10-04
- Source: 用户报告选日期后不能回任务池，已确认产品方案：普通新增默认今天，直接可见任务池选项，日期与任务池双向切换。

## PRD摘要

目标：选择过日期仍能撤销排期，任务池成为明确选项。用户：个人新增任务。核心：日期区任务池选项、上下文默认日期、无损切换。视觉：沿用快捷日期样式，任务池与日期选择同区，选中状态明确，不放更多。参考：当前TaskMaster日期快捷按钮与任务池，不新增任务类型/时间轴。

## 已确认规则

1. 普通新增入口默认今天（本地YYYY-MM-DD）。从明确某一天入口新增默认那一天；从任务池中新增默认任务池。普通“今天”视图的通用新增属于普通默认今天。相同交互入口优先按明确上下文，不能从任意筛选推断排期。
2. 日期区直接显示任务池选项，点击清除计划日期、取消其他日期高亮并显示任务池选中。保存为dueDate空、noTimeLimit=true。选择快捷或自定义日期会退出池状态、noTimeLimit=false，包括任何合法过去日期。
3. 用户主动清空日期仍进入任务池，选过日期后可回池再选日期，不要求关闭重开。只改计划日期及其池标记，标题、估时、优先级、分类、备注、硬截止等不丢。
4. 继承最新1小时默认和核心字段可见；编辑/恢复草稿保持已有日期或任务池选择，不能重新默认今天覆盖用户选择。草稿保存/恢复含清日期状态。
5. 重复任务既有首日期要求不变。用户可切任务池，但选择重复且无首日期时保存给出明确需要计划日期的反馈，不默默清除重复选项或替用户赋今天。
6. 普通新增/编辑已有排期选择保持可回任务池的体验；父任务容器不强加日期，父子模式不改变既有关系和子项默认，已有子项清日期能力不回退。
7. 手机当前添加页采用相同普通默认今天和直接任务池选择（手机无任务池管理视图），保持七天会话/反馈/幂等，未知结果重试不改变冻结payload。成功表单重置普通默认今天，只有成功才重置。

## 验收及失败

普通/指定日/池入口默认符合规则；日期→池→过去日期→清空双向切换，保存字段一致且只创建一条；其他输入不丢；草稿恢复不覆盖；不通过隐藏required拦截且错误可见；重复未选日期按既有要求可纠正；手机失败/未知重试不改变首次payload、成功reset今天；本地失败保留当前选择。验证真实DOM/事件与storage字段，不只字符串断言。

运行typecheck/lint/build/release/CSS及相关日期、草稿、父子、手机保存回归；全量既有静态失败单独报告。无GUI授权，真实Popup/宽屏/手机视觉待用户验收。只用虚构数据，不生产写入/清库/账号切换。
