## PRD摘要

目标：新增后知道保存到哪里，并能直接找到任务。用户：本人在Popup/新标签管理任务。核心：成功显示具体去向并提供查看；默认不跳视图。视觉：沿用现有反馈组件/按钮/任务高亮，不重新设计。参考：当前73成功toast与管理视图，扣除已交付内容，不重复重做无日期保存反馈。

## 范围及行为

扩展普通新建成功：无日期保留已添加到任务池提示；有日期明确已添加到YYYY-MM-DD（本地日期，含过去），并提供查看操作。查看只在用户主动点击时打开任务所在管理视图、定位该ID，关闭保存提示。Popup中查看可复用扩展管理新标签页，不把管理职责塞入手机。

不点查看保持当前视图，不强行跳转，不要求再次保存。提示在真正本地持久化成功且原表单收尾后显示，失败/冲突不成功提示，云失败单独反馈。提示展示需足够点击查看，不采用过快消失且不可操作的实现；沿用组件可访问性。只提供当前新增的任务定位，不增加搜索/新详情页或连续录入功能。

过滤条件导致目标不可见时，查看使用临时定位态显示该任务或明确提示并给解除筛选路径；不得静默改写用户永久筛选设置、把保存成功说为没有任务。目标已被删除/账号切换后给出明确不可查看提示，不恢复删除任务、不跨账号显示。父任务及子任务创建使用准确组结果，查看父任务/相关组，不把所有子项错误说成同一天；正常编辑原反馈不强行改流程。

移动端已是添加入口且无管理，不新增手机查看/列表/独立站点，本项无需Worker改动。兼容现有1小时默认、核心字段可见、日期空进池/过去可排、草稿/导入/历史数组兼容。
