# 备份导入去重合并

- Status: completed
- Confirmed date: 2026-10-03

- Revision: r2；2026-10-03 用户明确要求转开发。独立Issue创建后派发。

## PRD 摘要

目标：旧备份与当前数据能合并，反复导入不会产生两份任务，也不会丢失当前新增数据。用户：个人备份恢复、版本更新后衔接历史任务。核心：基于稳定ID去重、保留两边独有数据、处理同ID差异及删除历史。视觉：沿用现有导入入口，结果明确反馈；无需独立迁移工具。参考：TaskMaster已有JSON导出/导入和账号增量同步。

## 已确认行为

1. 导入语义为去重合并，不替换整库。同任务ID只保留一份；同文件重复导入不会增加任务。
2. 仅文件中存在的任务补入；仅当前版本存在的任务保留。
3. 同ID且内容不同识别冲突，不能直接以旧备份覆盖当前修改。冲突判定和选择规则在开发前细化，不仅依赖文件导出时间。
4. 不同ID但标题相同不直接删除，可能是不同任务；不做未经确认的模糊去重。
5. 分类及父子关系一起处理，不能产生丢失关系或重复分类。
6. 已删除任务不能因旧文件导入而无提示复活；缺少删除历史的旧格式需明确如何识别与处理，不能声称完全自动判断。
7. 结果反馈新增、合并、跳过数量及待处理冲突。仅真正持久化后报告成功，失败保留可恢复路径。
8. Google登录状态下同样遵守上述规则，同步后不得生成重复任务；访客仍可本地使用，不跨账号合并。

## 当前实现证据及影响

3.19.0 shared/storage.ts 的 importDataFromFile 校验 tasks/categories 后直接调用saveData，后者保存本地快照并异步增量同步。因此当前并非上述安全合并能力，不能向用户宣称已支持。现有导出格式版本字段固定3.10.0，校验不以版本号限制导入；后续需评估兼容旧备份与字段缺失，不因补格式破坏旧文件。

症状涉及扩展共享存储与导入事件，构建并Reload生效；账号同步和删除记录需纳入边界验证。是否需要后端改动由技术设计证据决定，不预先扩大范围。正式地址、扩展ID与现有账号不变。不清空真实数据、不新增物理迁移产品、不自动执行用户数据导入。

## 验收方向与执行配置

同文件导入两次任务数量不增加；两边独有任务保留；旧备份不会静默覆盖新修改或复活删除；分类父子关系完整；登录同步后其他端不重复。使用虚构数据验证，不写生产任务。当前未授权GUI，不声称视觉验收。

后续执行配置默认 gpt-6-luna / max，遵守用户最新偏好；工程量及用量在具体规格形成后评估。此前只记录暂缓；已由随后“转开发”解除，授权范围不含开发自动迁移真实用户数据。

## r2 交接规则：产品在已确认范围内补齐决策

### 导入流程和冲突

选择JSON后先只读解析、校验和预览，不立即写入。展示当前账号/访客上下文、预计新增/保留/冲突数量；普通无冲突流程只需一次“合并导入”。同ID相同有效内容跳过，不修改更新时间。只在文件中的合法任务待新增；只在当前的数据保留。

同ID内容不同默认保留当前，冲突详情按需展开，可逐项选择文件版本；禁止只按导出时间自动覆盖。选文件版本只替换可编辑业务字段，保留稳定ID与必要系统元数据，修改时间按实际导入写入产生。未选冲突不能阻塞保留当前的合并路径。不同ID同标题不做模糊去重或新建随机ID副本。重复导入的冲突可再次提示，但不得新增第二份任务。

分类按ID合并，同ID不同内容默认当前并支持明确选择；不同ID同名保留其真实身份，不擅自并表。父子引用需校验，引用缺失、ID重复但内容不同、无有效ID或非法结构时阻止写入并报告具体问题，不能静默丢行。文件内部相同ID相同内容可去重计入跳过。未知字段不能作为执行指令；不把凭证或后端连接配置从文件写入登录/同步设置。当前个性化设置保留，不因任务导入回滚。

### 删除与旧格式兼容

用当前账号已有的删除记录判断文件独有ID；已知删除记录默认跳过，恢复需用户在预览明确选择，不能因普通导入隐式复活。支持旧导出JSON，不要求用户先回旧版本升级数据。旧文件或本机缺少可靠删除历史时，预览明确说明“部分旧任务无法判断是否曾删除”，让用户检查待新增清单后再合并，不声称完全自动识别跨设备历史删除。不能为推断删除而导出同步凭证/设备私有游标。

导出保留稳定任务/分类ID及父子关系，补齐必要的格式标记/实际产品版本；新格式向后兼容读取旧data.tasks/categories。若确需新删除元数据，以最小可验证格式实施，不展开同步协议重构。

### 保存与账号一致性

生成预览时记录账号上下文与数据版本；确认前重新核对账号/当前数据，变化则重新合并预览，不用旧整库快照覆盖并发新增。保存是一次可验证本地持久化；失败不报告成功、不推进同步或清除原数据，可重新预览重试。不能整库回滚覆盖期间的新修改。

Google登录时沿用当前账号增量同步，只有本地合并成功才上传；云端失败单独显示“本地已导入，云同步待重试”，不要诱导重复新建。访客只本地，切换账号取消旧预览，不把前账号结果写入新账号。导入完成显示任务新增/更新/跳过/保留数量，分类单独统计；未解决冲突以保留当前计入保留，不把其称为成功覆盖。生产用户数据不由开发自动导入。
