# 移除手机端管理员旧版入口与连接页面

- Status: in_development
- Date: 2026-10-02
- GitHub Issue: https://github.com/Kairos-931/task-manager-chrome/issues/67
- Source: 用户要求记录第二项优化，手机端管理员旧版入口及旧版页面连接设置可以移除。

## 目标

手机端只呈现当前Google账号登录与添加任务路径，避免普通用户误入管理员旧版连接配置。

## 范围

移除新手机页中的管理员旧版入口，以及对应旧版手机页面/连接设置界面。旧版直接URL需在实现前选择清晰处理方式，推荐导航到当前手机登录页，避免已有书签进入失效页面；不能在重定向URL暴露或携带旧密钥。

不关闭后台旧API_TOKEN任务/同步接口，不改变Telegram或旧扩展通道，不删除生产业务数据，不自动撤销旧凭据。停用后台通道属于另一个需要实际兼容证据和明确批准的目标。

## 验收草案

- 当前手机页面不再出现管理员旧版入口或连接参数设置。
- 旧页面入口按确认的兼容策略处理，不继续暴露旧连接界面。
- 当前Google登录、添加任务正常；现有旧后端接口不被误删。

## 状态

本次仅记录，不编码、不部署。与手机保存反馈分开管理，不扩大正在进行的Google同步验收。实际Worker页面与路由需实现前核对，并决定旧URL处理后再交开发。

旧页面兼容策略：移除管理员旧入口和连接页面，旧页面导航到当前根登录页，不转发旧连接参数或密钥；后台旧API与Telegram不变。
