## PRD 摘要

目标：同一浏览器再次打开手机添加页无需每次点击Google登录。用户：已完成Google授权的手机快速添加使用者。核心：恢复已有有效TaskMaster会话，维持本地体验及账号隔离。视觉：沿用现有手机登录/账号卡片，恢复时清晰反馈，不闪烁误显示已登录。约束：保留现有固定7天会话，不默认延长、无限续期或存Google长时token；参考当前已实现会话而非新增认证系统。

## 行为与验收

1. 同一浏览器正常关闭/重开、刷新页面，若会话有效自动恢复账号，无需主动再点登录。
2. 先定位实际存储及启动恢复链路、网络失败处理、手机浏览器环境；不先假设只有sessionStorage问题，不在存储/恢复响应验证前声明成功。
3. 只有明确会话过期/失效、主动退出才引导重新认证；网络临时失败不能清除可能仍有效的会话，不泄漏账号数据或默默换号。
4. 退出或账号切换正确失效并隔离状态；7天有效期与服务端撤销仍有效，不无限续期。
5. 若浏览器隐私模式/外部应用内浏览器隔离存储导致无法保留，报告实际限制并给使用同一常规浏览器的清晰路径，不假称所有浏览器必然持久。
6. 凭证不进入URL、公开日志、聊天；检查已有会话存储的安全边界，采用最小改动，不新增用户配置或手机管理功能。

## 开发与发布

真实代码为backend/account-mobile.js及必要会话校验路径。与保存提示分开Issue/精确commit，单人串行，gpt-6-luna / max；核对线上行为、相关恢复/过期/退出/网络失败测试、项目验证与干净候选deploy dry-run。GUI未授权，使用确定性验证、真人用户后验收。用户已授权低风险可回退发布，无破坏性数据库变更、账号数据认领、push或新增依赖安装；出现这些边界须回产品。稳定URL保持不变，复用已安装Wrangler路径。
